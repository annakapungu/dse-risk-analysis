# DSE Stock Risk Analysis

This repository contains Python code used to analyze the risk characteristics of
CRDB Bank Plc, Tanzania Breweries Ltd (TBL), and Tanzania Cigarette Company (TCC)
listed on the Dar es Salaam Stock Exchange.

## Methods
- Daily return computation
- Value at Risk (VaR)
- Expected Shortfall (ES)
- Drawdown and CDaR
- Rolling volatility
- Dependence analysis

## Data
Daily adjusted closing prices obtained from the Dar es Salaam Stock Exchange.
